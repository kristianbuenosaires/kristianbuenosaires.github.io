# CuentiGo — Tus Cuentas contigo

Sitio informativo público del proyecto independiente Go Labs Studio: presentación, política de privacidad y términos de uso de CuentiGo 0.1.0.

Repositorio exclusivo de la web, rama `cuentigo-site`. No contiene el código de la aplicación Android, APK, respaldos, fotografías, credenciales ni archivos de otros proyectos.

La documentación legal es preliminar: falta confirmar el nombre legal y el domicilio del responsable antes del lanzamiento público. No anuncia aprobación por Google ni ofrece una descarga de la aplicación.

Publicación estática mediante GitHub Pages desde la raíz de `cuentigo-site`. Los enlaces son relativos para permitir migración a un dominio propio. Contacto: golabsstudio@gmail.com.
